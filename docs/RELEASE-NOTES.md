## Yellow Garden — ZyXer Labs

Un regalo de primavera en un jardín 3D: semilla, crecimiento, flores, ramo, carta y un final para descubrir. Incluye recorrido automático o manual, sonido opcional, ajustes de calidad y movimiento reducido.

### Usar en Windows

Descarga **YellowGarden-Setup-VERSION-x64.exe** en Assets (el nombre incluye el número de esta versión). Ábrelo y sigue el instalador. Se crean accesos directos en el escritorio y menú Inicio. La aplicación funciona sin conexión y no requiere Node.js. Compatible con Windows 10/11 de 64 bits (x64); otras arquitecturas no están verificadas.

Este instalador todavía no tiene firma digital de editor. Windows puede mostrar un aviso de aplicación desconocida. El archivo SHA256SUMS.txt permite comparar la integridad de la descarga; no sustituye una firma de identidad. No desactives las protecciones del sistema.

### Navegador o código

El README del repositorio explica cómo abrir la web de GitHub Pages, ejecutar el código, personalizar mensajes y compilar el programa. No necesitas instalar la aplicación para visitar la web. Las actualizaciones de Windows se descargan e instalan manualmente desde Releases.

### Límites

El jardín usa WebGL y su fluidez depende de la GPU. Prueba calidad Ligera si lo necesitas. La aplicación no conserva el punto del recorrido al cerrarla. No incluye sincronización, cuentas ni actualizaciones automáticas.
